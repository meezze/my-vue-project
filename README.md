# Daxi Teleprompter

Минималистичный суфлёр для сценариев Daxi. Работает как один статический HTML-файл без сборки и зависимостей.

## Управление

- **Старт / Пауза** — автопрокрутка
- **Скорость** — скорость прокрутки
- **A− / A+** — размер текста
- **↔** — зеркальный режим
- **Скрыть** — убрать интерфейс
- **⛶** — полный экран
- Тап по тексту — старт / пауза
- Двойной тап — скрыть / показать интерфейс

Настройки скорости, размера текста, выбранного сценария и зеркального режима сохраняются в браузере.

## Тексты

В суфлёр вынесены только произносимые реплики. Блоки «Визуал» и «Экран» намеренно не отображаются. Формулировки реплик сохранены как в исходном тексте.
